# Verto Studio previews

Public delivery repository for the studio-created landing page and reviewed encrypted previews. Each preview directory contains a generic browser loader and an AES-256-GCM envelope. Access keys are distributed separately and are never stored in this repository.

Contact databases, correspondence, plaintext customer pages and photographs, QA reports, local paths, private mappings and credentials are excluded. Encrypted content can be opened only with the complete private viewing link; recipients can save or forward their copy. This does not provide account authentication, expiry or revocation of downloaded copies.

Each release uses an exact reviewed file allowlist. Publication here does not establish ownership or public reuse rights for source materials.
